# WebTorq — All-in-One Website Subscription Agency

A clean, professional, high-converting agency website designed for **WebTorq**: providing **all-in-one website builds, legacy site overhauls, high-speed cloud hosting, and unlimited ongoing updates for 1 flat monthly subscription**.

---

## ⚡ Highlights & Key Features

1. **Interactive Before & After Website Modernization Slider**:
   - Draggable split slider directly comparing a dated legacy business website against a modern high-converting redesign.
   - Quick preset buttons (100% Old, 50/50 Split, 100% Modern Redesign).

2. **The "Death of the $15,000 Agency Invoice" Comparison Table**:
   - Clear corporate table contrasting Traditional Agencies ($10k+ upfront, months of delay, hourly fees) vs. Freelancers vs. **WebTorq**.

3. **Live 60-Second Website Diagnostic Scanner**:
   - Diagnostic tool where potential clients enter their existing URL and receive an instant modernization score, speed diagnosis, and tailored upgrade blueprint.

4. **Interactive First-Year Cost & Savings Calculator**:
   - Dynamic slider allowing leads to compare upfront agency quotes against WebTorq's predictable flat subscription.

5. **Market-Approved Affordable Pricing Tiers**:
   - **Starter Launch ($99/mo)** — Solo pros & trades, up to 5 pages, hosting + SSL, 3 monthly updates.
   - **Growth & Redesign ($189/mo)** — Most Popular: complete overhaul or build, unlimited updates, 48h turnaround, booking & lead sync, 95+ PageSpeed.
   - **Scale & E-Commerce ($349/mo)** — Multi-location, e-commerce, 2 concurrent active requests, same-day urgent queue.

6. **3 High-Conversion Buyer Guarantees**:
   - 100% Code & Asset Ownership (no hostage lock-in).
   - 14-Day 100% Money-Back Guarantee.
   - Pause ($29/mo) or Cancel anytime with 1 click.

## 🚀 Quick Start / Local Preview

The local server runs via `node server.js` on `http://localhost:3000`.

To start manually:
```bash
node server.js
```
Or open `index.html` directly in your browser.
